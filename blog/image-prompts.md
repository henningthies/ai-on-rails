# Image Prompts for Triangle Series

## Style Guide (include with each prompt)

```
STYLE: Dark, minimal, industrial aesthetic. 
COLORS: Deep charcoal background (#1C1917), warm amber/orange accents (#D97706), subtle gold highlights (#F59E0B). 
MOOD: Professional, tech-forward, premium. 
TEXTURE: Subtle grain/noise overlay. 
LIGHTING: Dramatic, focused, with soft amber glow effects.
NO: People's faces, stock photo feel, busy backgrounds, blue tones.
FORMAT: 16:9 aspect ratio, suitable for blog header.
```
