So arbeiten wir

Mit euren Daten und Systemen

  • Ihr seht jede Woche den aktuellen Stand.

In eurem Repository

  • Jede Änderung kommt als Pull Request in euer Repository.

  • Ein Mensch prüft jede Änderung vor dem Deployment.
